# 한국 부동산 실거래가 분석 대시보드

국토교통부 실거래가 데이터를 기반으로 아파트 거래 현황을 시각화하는 웹 대시보드입니다.
엑셀 파일을 업로드하면 지역별, 기간별 가격 추이를 차트로 바로 확인할 수 있습니다.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| 엑셀 파일 업로드 | 국토교통부 실거래가 엑셀을 그대로 불러올 수 있습니다 |
| 가격 추이 차트 | 월별/기간별 아파트 실거래가 변화를 선 그래프로 표시 |
| 지역 필터 | 시/도, 구/군 단위로 데이터를 필터링 |
| 한글 금액 표시 | 가격 축을 억원 단위 한글로 자동 변환 |
| 자동 포맷 감지 | 구형/신형 국토부 API 데이터 형식을 자동으로 인식 |

---

## 시작하기 전에 필요한 것

- **Python 3.8 이상** ([다운로드](https://www.python.org/downloads/))
- 국토교통부 실거래가 엑셀 파일 ([실거래가 공개시스템](https://rt.molit.go.kr))

---

## 설치 방법

### 1단계: 저장소 복제

```bash
git clone https://github.com/pyh9965/real-estate-dashboard-korea.git
cd real-estate-dashboard-korea
```

### 2단계: 필요한 패키지 설치

```bash
pip install -r requirements.txt
```

설치되는 패키지:

| 패키지 | 용도 |
|--------|------|
| streamlit | 웹 대시보드 화면 구성 |
| pandas | 데이터 처리 및 분석 |
| plotly | 인터랙티브 차트 생성 |
| openpyxl | 엑셀 파일 읽기 |

---

## 실행 방법

### Windows (배치 파일로 간편 실행)

탐색기에서 `간단실행.bat` 파일을 더블클릭하면 자동으로 실행됩니다.

### Mac / Linux (터미널)

```bash
streamlit run app.py
```

### 실행 후

브라우저가 자동으로 열리며 아래 주소로 접속됩니다:

```
http://localhost:8501
```

---

## 사용 방법

1. **엑셀 파일 준비** - 국토교통부 실거래가 공개시스템에서 원하는 지역/기간의 데이터를 다운로드합니다
2. **파일 업로드** - 대시보드 화면에서 엑셀 파일을 업로드합니다
3. **지역 선택** - 사이드바에서 분석할 지역을 선택합니다
4. **차트 확인** - 자동으로 가격 추이, 거래량 등 차트가 표시됩니다

## 파일 구조

```
real-estate-dashboard-korea/
├── app.py                  # 메인 대시보드 (여기서 실행)
├── data_transformer.py     # 데이터 형식 자동 변환
├── region_code_mapper.py   # 지역 코드 매핑
├── requirements.txt        # 필요한 패키지 목록
├── 간단실행.bat            # Windows 간편 실행 파일
└── start_app.bat           # Windows 실행 파일 (대안)
```

## 자주 묻는 질문

**Q. 엑셀 파일을 올렸는데 오류가 나요.**
A. 국토교통부 실거래가 공개시스템에서 직접 다운로드한 파일인지 확인하세요. 임의로 수정한 파일은 인식이 안 될 수 있습니다.

**Q. 브라우저가 자동으로 열리지 않아요.**
A. 브라우저 주소창에 `http://localhost:8501`을 직접 입력해서 접속하세요.

**Q. pip install이 안 돼요.**
A. `pip install --upgrade pip` 명령으로 pip를 최신 버전으로 업그레이드한 후 다시 시도하세요.
